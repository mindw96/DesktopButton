도움말 및 문의

Folder In Bar(폴더인바)는 메뉴 막대에서 사용하는 Mac 앱입니다. macOS 13 이상이 필요합니다.

언어 선택 (1.1.0부터)

한국어와 영어를 지원하며 macOS의 선호 언어 또는 Folder In Bar에 지정한 앱별 언어를 따릅니다. 지원되는 선호 언어가 없으면 영어로 표시합니다. macOS 시스템 설정에서 앱별 언어를 변경한 뒤에는 Folder In Bar를 종료하고 다시 실행하세요. 파일명·폴더명과 기존 폴더 연결·보기·정렬·로그인 설정은 유지됩니다.

처음 사용하기

  1. 앱을 실행한 뒤 화면 위쪽 메뉴 막대의 폴더 아이콘을 누릅니다. 기본 상태에서는 Dock에 아이콘이나 일반 창이 나타나지 않습니다.
  2. “폴더 연결…(Connect Folder…)”을 누르고 바탕화면, 다운로드 등 사용할 폴더 하나를 선택합니다.
  3. 메뉴 막대의 폴더 아이콘을 다시 누르면 연결한 폴더의 항목이 보입니다. 1.1.0부터는 목록·격자에서 한 번 클릭해 선택하고, 더블클릭하거나 선택 후 Return을 눌러 기본 앱이나 Finder에서 엽니다. 이전 1.0.0은 한 번 클릭으로 엽니다.

파일과 사진을 다른 앱으로 드래그하기

먼저 파일을 받을 앱의 첨부 영역이나 드롭 영역을 열어 두세요. Folder In Bar의 목록에서 파일 행을 누른 채, 또는 격자에서 아이콘을 누른 채 해당 영역으로 드래그해 놓습니다. 파일 하나씩 전달할 수 있으며, 원본을 옮기거나 지우지 않고 복사 방식으로 전달합니다.

ChatGPT 등 대상 앱에서 첨부를 받는 위치와 지원하는 파일 형식·크기를 확인해 주세요. 받는 앱에 따라 파일을 첨부하거나 열며, 지원하지 않는 항목이나 위치에는 놓을 수 없을 수 있습니다. 드래그할 때는 파일을 누른 상태로 포인터를 이동하세요.

사용자가 전달한 파일은 대상 앱의 기능과 개인정보 처리방침에 따라 처리되거나 업로드될 수 있습니다. Folder In Bar 자체는 파일을 서버로 업로드하지 않습니다.

보기와 창 크기 바꾸기

창 오른쪽 위의 목록·격자 버튼으로 보기 방식을 바꿉니다. 아래쪽 모서리의 대각선 화살표를 드래그하면 창의 폭과 높이를 조절할 수 있습니다. 선택한 보기 방식과 크기는 다음 실행에도 유지됩니다.

폴더의 변경 사항은 창을 다시 열거나 새로고침 버튼(⌘R)을 눌러 확인할 수 있습니다. 숨겨진 파일은 표시하지 않습니다.

아이콘 크기 바꾸기 (1.1.0부터)

창 아래의 톱니바퀴 설정(Settings)에서 “아이콘 크기(Icon Size)”를 열고 “작게(Small)”, “보통(Medium)”, “크게(Large)” 중 하나를 선택하세요. 목록과 격자 모두에 적용되며 다음 실행에도 유지됩니다. 기본값은 “보통”입니다. 격자에서는 아이콘 크기와 창 폭에 맞춰 한 줄의 항목 수가 바뀝니다.

파일 정렬하기 (1.1.0부터)

상단의 위·아래 화살표 “정렬(Sort)” 메뉴에서 이름·종류·크기·태그·응용 프로그램을 선택합니다. “날짜(Date)” 안에는 최근 사용일·추가된 날짜·수정일·생성일이 있습니다. 오름차순·내림차순을 선택할 수 있으며, 목록·격자 보기와 새로고침·재실행에도 설정이 유지됩니다. 응용 프로그램은 파일을 여는 기본 앱을 뜻하고, 태그는 태그 이름을 기준으로 정렬합니다.

macOS나 파일시스템에서 제공하지 않는 날짜·기타 정보는 정렬 방향과 관계없이 마지막에 표시됩니다. 크기는 일반 파일에 적용하며 폴더와 패키지 내부의 전체 크기는 계산하지 않습니다. 정렬은 원본 파일의 내용·날짜·태그를 바꾸지 않습니다.

정렬 기준이나 방향을 바꾼 뒤에도 폴더 창 바깥을 클릭하면 창이 닫힙니다. Esc로 닫을 수도 있습니다.

폴더를 바꾸거나 다시 연결하기

창 아래의 “폴더 다시 연결…(Reconnect Folder…)”을 눌러 다른 폴더를 선택합니다. 폴더가 이동했거나 접근할 수 없다는 안내가 나오면 같은 방법으로 다시 연결해 주세요. 이 작업은 파일을 이동하거나 삭제하지 않습니다.

로그인 시 자동 실행과 Dock 아이콘

창 아래의 톱니바퀴 설정에서 “로그인 시 자동 실행(Launch at Login)”과 “Dock에 아이콘 표시(Show Icon in Dock)”를 선택할 수 있습니다. 로그인 항목에 “승인 필요(Approval Required)”가 표시되면 안내에 따라 macOS 시스템 설정에서 허용해 주세요. Dock 아이콘을 표시한 상태에서는 아이콘을 클릭해 폴더 창을 열 수 있습니다.

전체 화면에서 메뉴 막대가 보이지 않나요?

포인터를 화면 위쪽 끝으로 옮겨 메뉴 막대를 표시한 뒤 폴더 아이콘을 누르세요. 메뉴 막대 아이콘이 많은 경우 macOS의 표시 공간에 따라 일부 아이콘이 가려질 수 있습니다.

Mac App Store에서 설치한 버전은 App Store의 업데이트 기능으로 업데이트합니다.

문의하기

오류 제보, 사용 방법, 기능 제안은 GitHub에서 문의 작성으로 보내주세요. 기존 문의는 문의 목록에서 확인할 수 있습니다. 새 문의 작성에는 GitHub 계정이 필요합니다.

macOS 버전, 앱 버전, 문제가 발생한 순서를 알려주시면 확인에 도움이 됩니다. 문의는 공개되므로 개인 파일, 비밀번호, 민감한 경로나 개인정보가 담긴 화면을 올리지 말아 주세요.

English support

Folder In Bar requires macOS 13 or later. Starting with 1.1.0, the interface supports English and Korean, following your macOS preferred languages or the language chosen specifically for Folder In Bar. If none of your preferred languages is supported, the app uses English. After changing the app language in macOS System Settings, quit and reopen Folder In Bar. Filenames, folder names, connections, and saved preferences remain unchanged.

After launching, click the folder icon in the menu bar; a regular window and Dock icon are not shown by default. Choose “Connect Folder…” (폴더 연결…) to connect one folder. Open the menu again to browse its contents. Use “List View” or “Grid View” to switch views and the diagonal-arrow handle to resize the panel. In the Settings gear menu, choose “Show Icon in Dock” or “Launch at Login” as needed. To change folders, choose “Reconnect Folder…” (폴더 다시 연결…). Version 1.0.0 uses Korean menu labels.

Starting with 1.1.0, a single click selects an item in either list or grid view. Double-click it, or press Return after selecting it, to open the file or folder. Version 1.0.0 opens items with a single click. In 1.1.0, choose “Icon Size” (아이콘 크기) in the Settings gear menu, then “Small” (작게), “Medium” (보통), or “Large” (크게). The setting applies to both views and persists after relaunch; the default is Medium.

To drag a file or photo, first open a file drop or attachment area in the destination app. Press and hold a file row or grid icon, then drag it onto that area. Files are handed off one at a time for copying; this operation does not move or delete the original. The destination app controls accepted file types, size limits, drop locations, and whether the file is attached or opened. Folder In Bar does not itself upload files, but an app you drop a file into may process or upload it under its own privacy policy.

Starting with 1.1.0, the up/down-arrow “Sort” menu offers “Name”, “Kind”, “Size”, “Tags”, and “Application”. The “Date” submenu offers “Date Last Opened”, “Date Added”, “Date Modified”, and “Date Created”. Choose “Ascending” or “Descending”; the choice is shared by list/grid views and persists after refresh and relaunch. Application means the default app used to open a file. Missing metadata sorts last in either direction. Size applies to regular files, without recursively measuring directories or packages. Sorting does not change file contents, dates, or tags.

After changing a sort option, clicking outside the folder panel closes it. You can also press Esc to close the panel. Dragging files into other apps remains available.

For help or bug reports, open a GitHub issue. Please include your macOS version, app version, and steps to reproduce the issue. Issues are public; do not include private files or sensitive information. Mac App Store editions receive updates through the App Store.
