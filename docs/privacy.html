수집하는 데이터가 없습니다

Folder In Bar는 개인정보, 사용 기록, 파일 이름이나 파일 내용을 개발자 또는 제3자 서버로 전송하지 않습니다. 계정 가입, 광고, 분석 도구, 추적 기능을 사용하지 않으며 개발자가 운영하는 서버에 사용자 데이터를 저장하지 않습니다.

폴더 접근과 Mac에 저장되는 설정

사용자가 macOS의 폴더 선택 창에서 허용한 폴더에 접근해 항목의 이름과 아이콘을 표시합니다. 항목을 선택하면 macOS에 요청하여 기본 앱 또는 Finder에서 엽니다. 파일을 업로드하거나 앱이 직접 수정·삭제하지 않습니다.

다음 실행에도 같은 폴더를 사용할 수 있도록 폴더 접근 정보(보안 범위 북마크)를 Mac의 앱 설정에 저장합니다. 보기 방식, 창 크기, Dock 아이콘 표시 여부도 Mac에 저장합니다. 로그인 시 자동 실행은 사용자가 선택한 경우 macOS의 로그인 항목으로 등록됩니다.

사용자의 선택과 보관

“폴더 다시 연결…”에서 다른 폴더를 선택하면 기존 폴더 연결 정보가 새 연결 정보로 바뀝니다. 로그인 시 자동 실행은 앱 설정이나 macOS 시스템 설정에서 끌 수 있습니다. 앱이 저장하는 설정은 앱을 종료해도 Mac에 남으며, 개발자가 원격으로 접근하거나 삭제할 수 없습니다. 앱을 삭제하더라도 macOS에 일부 로컬 설정이 남을 수 있습니다.

외부 앱과 웹사이트

파일을 여는 기본 앱, App Store, 도움말 및 문의 링크로 방문하는 GitHub 등 외부 서비스에는 각 서비스의 개인정보 처리방침이 적용됩니다. 이 웹사이트는 GitHub Pages에서 제공하며 별도의 분석·광고 스크립트를 포함하지 않습니다. GitHub의 웹사이트 접속 정보 처리에 대해서는 GitHub 개인정보 처리방침을 확인해 주세요.

문의 및 변경

개인정보 관련 문의는 도움말 및 문의 페이지에서 접수할 수 있습니다. 공개 문의에는 개인 파일, 비밀번호 등 민감한 정보를 포함하지 말아 주세요. 이 방침이 변경되면 이 페이지의 수정일과 내용을 갱신합니다.

Privacy Policy

Applies to the Mac App Store edition of Folder In Bar.
Last updated: November 11, 2026.

No data collection

Folder In Bar does not send personal information, usage activity, filenames, or file contents to the developer or third-party servers. The app has no accounts, advertising, analytics, or tracking, and the developer does not operate a server that stores user data.

Local folder access and preferences

The app accesses the folder you authorize using the macOS folder picker to display item names and icons. Selecting an item asks macOS to open it in its default app or Finder. Folder In Bar does not upload, modify, or delete your files.

A security-scoped bookmark is stored in the app's local preferences so the folder can be reopened later. Your view mode, panel size, and Dock visibility preference are also stored on your Mac. Launch at login is registered with macOS only when you enable that option.

Your choices and retention

Choosing a different folder replaces the saved folder connection. You can disable launch at login in the app or macOS System Settings. Local settings remain after quitting the app, and some may remain after uninstalling it. The developer cannot access or delete these settings remotely.

Other apps and websites

Apps used to open files, the App Store, and websites opened from support links are governed by their own privacy policies. This website is hosted on GitHub Pages and includes no added analytics or advertising scripts. See the GitHub Privacy Statement for GitHub's handling of website visits.

Contact and changes

Please use the support page for privacy questions. Do not post private files, passwords, or other sensitive information in public issues. Changes to this policy will be reflected on this page with an updated date.
