# Mac App Store 제출 자료

Folder In Bar 1.0.0 (빌드 7)의 제출 자료입니다. 무료 배포와 심사 승인 후 자동 공개는 사용자가 선택한 설정입니다. 이 문서의 준비 상태는 App Store Connect 업로드·심사 제출·승인 상태를 뜻하지 않습니다.

- `metadata.json`: 한국어 소개 문구, URL, 카테고리와 공개 설정
- `review-notes.txt`: 심사 담당자에게 전달할 영문 사용 절차
- `../privacy.html`: Mac App Store 배포판의 개인정보 처리방침
- `../support.html`: 사용 방법과 문의 경로

리뷰 연락처는 App Store Connect에만 입력하고 저장소에는 보관하지 않습니다. 개인정보 응답은 최종 Store 빌드에 외부 수집 코드가 없는 것을 확인한 뒤 **데이터 수집 안 함**으로 설정합니다. 계정 가입, 광고, 앱 내 구입, 사용자 간 메시지 또는 사용자 제작 콘텐츠를 제공하지 않습니다.

## 스크린샷 준비

실제 Store 빌드에서 개인 정보가 없는 예시 폴더를 연결하여 촬영합니다. 기존 직접 배포판의 업데이트 메뉴가 보이는 화면은 사용하지 않습니다. 업로드할 파일은 투명 채널이 없는 PNG 또는 JPEG이며, 다음 크기 중 하나를 사용합니다: 1280×800, 1440×900, 2560×1600, 2880×1800.

1. 아이콘 격자 보기: 여러 종류의 예시 파일과 연결한 폴더 이름
2. 목록 보기: 같은 폴더의 파일 이름을 확인할 수 있는 화면
3. 설정 또는 크기를 조절한 화면: Dock 아이콘·로그인 실행 옵션 또는 넓어진 격자

촬영 전까지 스크린샷은 준비되지 않은 상태입니다. 생성하거나 재구성한 가짜 앱 화면으로 대체하지 않습니다.
